Eficiencia

Inteligencia por vatio

Investigadores del Hazy Research Lab y del Scaling Intelligence Lab de Stanford probaron Inkling 2 Mini con acceso anticipado. Miden cuánta energía necesita un modelo por consulta para alcanzar cierto nivel de rendimiento. Una puntuación más alta es mejor.

Inteligencia por vatio (Stanford)

Inkling 2 Mini corrió en una NVIDIA DGX Spark (128 GB) con precisión MXFP8 y esfuerzo de razonamiento bajo. Los demás corrieron en NVFP4 (Qwen3.6-35B-A3B y Gemma-4-26B-A4B) e INT4 (Qwen3.5-27B). Método: Intelligence per Watt, Saad-Falcon y Narayan et al., 2025.

Varios agentes persistentes en un solo equipo.

Los 20 habitantes de Thinkyville, un pueblo atento a su consumo de energía, los gestiona Inkling 2 Mini en un único MacBook sin conexión.

Descarga

Bájalo a tu máquina

Los pesos están en Hugging Face. Elige la vía que te venga mejor; todas descargan el repositorio completo y reanudan si se corta la conexión.

Abrir en Hugging Face

  • Espacio20,2 GB de pesos. Deja unos 25 GB libres por la caché.
  • SoftwarePython 3.9 o superior para las opciones de abajo.
  • Para ejecutarloConsulta el README del repositorio para el motor de inferencia y los requisitos exactos.

Windows: script .bat

Guárdalo como descargar_inkling2_mini.bat y haz doble clic. Instala las dependencias y descarga el modelo en una carpeta junto al archivo.

Ver el script 
@echo off
setlocal

REM ============================================================
REM  Descarga thinkingmachines/Inkling-2-Mini (~20 GB) desde Hugging Face
REM  Requisitos: Python 3.9+ en el PATH y ~25 GB libres en disco.
REM  Si se corta, vuelve a ejecutarlo: reanuda lo ya descargado.
REM ============================================================

set "HF_REPO=thinkingmachines/Inkling-2-Mini"
set "HF_DEST=%~dp0Inkling-2-Mini"

REM Si el repo pidiera acceso, descomenta y pon tu token (https://huggingface.co/settings/tokens):
REM set "HF_TOKEN=hf_xxxxxxxxxxxxxxxxxxxx"

REM Opcional: cambiar la carpeta de cache si el disco C: es pequeno
REM set "HF_HOME=D:\hf_cache"

where python >nul 2>&1
if errorlevel 1 (
    echo [ERROR] No se encuentra Python en el PATH. Instalalo desde https://www.python.org/downloads/
    echo         y marca "Add Python to PATH" durante la instalacion.
    pause
    exit /b 1
)

echo.
echo [1/2] Instalando/actualizando huggingface_hub y hf_xet...
python -m pip install -U "huggingface_hub[cli]" hf_xet
if errorlevel 1 (
    echo [ERROR] Fallo al instalar las dependencias.
    pause
    exit /b 1
)

echo.
echo [2/2] Descargando %HF_REPO% en:
echo       %HF_DEST%
echo.
python -c "import os; from huggingface_hub import snapshot_download; snapshot_download(repo_id=os.environ['HF_REPO'], local_dir=os.environ['HF_DEST'])"
if errorlevel 1 (
    echo.
    echo [ERROR] La descarga fallo. Comprueba tu conexion, el espacio en disco
    echo         y, si el repo lo exige, el token. Vuelve a ejecutar para reanudar.
    pause
    exit /b 1
)

echo.
echo [OK] Descarga completada: %HF_DEST%
pause
endlocal
